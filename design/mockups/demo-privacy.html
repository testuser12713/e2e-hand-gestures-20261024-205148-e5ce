Privacy

On-device only

  • Nothing leaves the browser

    No video frame and no landmark is stored or sent anywhere. There is no telemetry.

  • Only model files are fetched

    Requests go to assetBaseUrl for the MediaPipe wasm and model, and only after you start. It accepts https: or relative URLs.

  • The default CDN sees your IP

    Self-host the assets and point assetBaseUrl to them to avoid that.

Error Start gestures

assetBaseUrl must start with https:// or be a relative URL. The value "javascript:alert(1)" was rejected.
