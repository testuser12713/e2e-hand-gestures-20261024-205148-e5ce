Adapters

    reveal.js

    Calls next, prev, up, down, togglePause and toggleOverview directly.

    Any keyboard tool

    Dispatches arrow keys, B and O to the document. The mapping can be overridden.

    Any object with a handle method receives every gesture and its timestamp.
